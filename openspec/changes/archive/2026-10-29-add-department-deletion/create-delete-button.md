# Задача
Добавить кнопку "Удалить" в каждой строке таблицы.
При нажатии на кнопку необходимо открыть модальное окно с текстом 
"Вы хотите удалить <название департамента>. Данное действие отменить невозможно. Если вы дествительно хотите удалить - введите название департамента в поле ниже"
Ниже надписи должно быть поле куда необходимо ввести название департамента, которое хотим удалить
Кнопка "Удалить" неактивна пока название департамента, введенное в поле, не совпадет с названием департамента, которое хотят удалить.
После ввода департамента и нажатия на кнопку идет "кружок", показывающий таймер (5 секунд) перед удалением и кнопку отмена удаления (если вдруг пользователь захотел отменить действие)
Так же у модального окошка должен быть "крестик", по нажатии на который пользователь может закрыть модальное окно.

Так же приветствуются твои предложения какими функциями можно дополнить процесс удаления департамента.
