# Proposal

## Why

В приложении до сих пор нет экрана департаментов: `src/App.js` остаётся заглушкой CRA, хотя спека `department-catalog` уже описывает таблицу и навигацию. Задача `openspec/tasks/01 - постраничный вывод департаментов.md` добавляет к этому постраничный вывод, старт только с `FACTORY`, раскрытие дочерних узлов по «+» и легенду над таблицей. Бэкенд для этого уже подготовлен, но контракт на GitHub и в локальной ветке различается.

## What Changes

- Появляется страница «Департаменты»: корневой список — только департаменты типа `FACTORY`, с серверной пагинацией.
- У строки с дочерними департаментами отображается «+»; по нажатию дочерние департаменты подгружаются и показываются с отступом. Повторное нажатие сворачивает узел.
- Раскрытие работает рекурсивно для любого типа, а не только для `FACTORY` → `WORKSHOP`.
- Над таблицей появляется легенда, объясняющая, что показывает таблица и как читать иерархию.
- Добавляется слой API для обращений к бэкенду и обработка состояний загрузки, пустого списка и ошибок.
- Спека `department-catalog` уточняется: стартовый набор — `FACTORY` (а не «корневые без родителя»), добавляются пагинация, раскрытие дочерних узлов и легенда.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `department-catalog`: меняется правило выбора стартового уровня (только `FACTORY`), добавляются постраничный вывод, ленивая загрузка дочерних узлов и легенда над таблицей.

## Impact

- `src/App.js` и новые компоненты страницы департаментов, таблицы, строки-дерева, пагинации и легенды.
- Новый слой `src/services` для работы с API департаментов.
- Контракт бэкенда: `GET /api/v1/departments/all-by-type` и `GET /api/v1/departments/by-parent`; поле `hasChildren`.
- CORS бэкенда для `http://localhost:3000` либо dev-proxy в CRA.
- Существующая спека `openspec/specs/department-catalog/spec.md` (delta будет создана при возврате к задаче).
- Тесты на API-слой и поведение таблицы (сейчас тестовых файлов нет).

## Open Questions

- Какой контракт считать целевым: GitHub-ветка или локальное состояние с `/by-parent`, `hasChildren` и CORS?
- Пагинировать ли детей внутри узла («Показать ещё») или грузить их целиком?
- Входит ли в change боковое меню и заглушки из спеки, или только таблица департаментов?
