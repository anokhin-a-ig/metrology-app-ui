# Proposal

## Why

Каталог департаментов умеет только просматривать иерархию, хотя бэкенд уже поддерживает создание департаментов. Пользователю нужна кнопка «Новый» и модальное окно, чтобы добавлять заводы, цеха, участки и лаборатории без выхода из раздела «Департаменты».

## What Changes

- На странице «Департаменты» появляется кнопка «Новый», открывающая модальное окно создания.
- Поля формы: «Название», «Тип», «Входит в состав».
- «Входит в состав» — combobox с серверным поиском по части имени; для `FACTORY` поле очищается и блокируется, для остальных типов родитель обязателен.
- Кнопки «Добавить» (зелёная) и «Отмена» (красная); ошибки валидации и сервера показываются внутри окна.
- После успешного создания окно закрывается, дерево обновляется точечно: перезагружается текущая страница корня для `FACTORY` либо ранее загруженные страницы детей выбранного родителя.
- Слой API расширяется созданием департамента и поиском по имени.
- Бэкенд получает регистронезависимую уникальность и поиск для кириллицы через функциональный ICU-индекс, native-запросы и обработчик нарушения целостности.
- Поиск департаментов возвращает лёгкий DTO без `parent` и `hasChildren`, чтобы убрать N+1.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `department-catalog`: добавляется требование создания департамента с модальной формой, поиском родителя, валидацией, обработкой ошибок и обновлением дерева.

## Impact

- UI: `src/components/Departments/DepartmentsPage.js`, новые `DepartmentCreateModal`, `ParentCombobox` и стили; `src/services/departments.js`.
- API: `POST /api/v1/departments`; `GET /api/v1/departments/search-by-name`.
- Бэкенд `metrology-app`: Liquibase changeset с ICU-индексом, `DepartmentRepository`, `DepartmentService`, `DepartmentDtoService`, `DepartmentController`, `GlobalExceptionHandler`.
- Тесты UI и бэкенда; production-сборка и ESLint.
