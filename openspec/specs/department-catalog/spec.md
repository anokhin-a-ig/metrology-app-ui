# Department Catalog Specification

## Purpose

Позволяет пользователям просматривать иерархию подразделений предприятия в виде древовидной таблицы.

## Requirements

### Requirement: Отображение списка департаментов

Система SHALL отображать департаменты в виде таблицы со столбцами: Название, Тип, Родительское подразделение.

#### Scenario: Загрузка списка департаментов

- **WHEN** пользователь открывает страницу «Департаменты»
- **THEN** система запрашивает данные и отображает таблицу с корневыми департаментами

### Requirement: Древовидная структура

Система SHALL отображать департаменты в виде дерева. При загрузке видны только корневые узлы (без родителя). Пользователь может раскрыть узел, чтобы увидеть дочерние департаменты.

#### Scenario: Раскрытие узла

- **WHEN** пользователь нажимает на иконку раскрытия рядом с департаментом
- **THEN** система отображает дочерние департаменты с отступом

#### Scenario: Сворачивание узла

- **WHEN** пользователь нажимает на иконку сворачивания раскрытого департамента
- **THEN** система скрывает дочерние департаменты

### Requirement: Навигационное меню

Система SHALL отображать боковое меню с пунктами: Департаменты, Приборы, Сотрудники. Пункты «Приборы» и «Сотрудники» отображают заглушку «Появится скоро».

#### Scenario: Открытие страницы департаментов

- **WHEN** пользователь нажимает «Департаменты» в меню
- **THEN** система отображает таблицу департаментов

#### Scenario: Открытие заглушки

- **WHEN** пользователь нажимает «Приборы» или «Сотрудники» в меню
- **THEN** система отображает текст «Появится скоро»
