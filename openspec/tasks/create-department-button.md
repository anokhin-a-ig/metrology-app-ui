# Задача
Сделать кнопку "Новый". По нажатии на кнопку открывается модальное окно для создания нового департамента.
В модальном окне поля "Название", "Входит в состав", "Тип"
Поле "Входит в состав" должно быть выпадающим списком с возможностью поиска по имени.

Так же должно быть две кнопки: "Добавить" и "Отмена"
Кнопка "Добавить" зеленого цвета, кнопка "Отмена" - красного
