# Задача
Необходимо сделать отображение таблицы департаментов во вкладке "Департаменты"
Таблица должна быть древовидной. Сначала полностью отображаются все департаменты типа FACTORY
У каждого департамента должен быть знак + который позволяет раскрывать список под родительским FACTORY 
и показывать дочерние. Так для каждого типа.
